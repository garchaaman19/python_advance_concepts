# Context window problem 
1. Sliding window approach 
    - Retain the most recent exchanges in the context window. 
    - Summarize or discard older exchanges as the conversation progresses.

# Chunking Techniques
1. Fixed-Length Chunking
    -  Divide the input into chunks of a fixed size, based on token or word count.
2. Sentence-Based Chunking
    - Break the text into chunks at sentence boundaries. 
3.  Paragraph-Based Chunking 
    -  Split the input at paragraph boundaries.
